# Mont-Blanc Wedding Planner

Interactive 3D wedding reception planner for **La Sirène Banquet – Salle Mont-Blanc**.

## Venue geometry used

The 3D shell follows the venue floor plan supplied by the couple:

- 35 ft maximum width
- 62 ft total length
- 12.5 ft ceiling height
- 1,930 ft² listed area
- banquet capacity 120
- 27 ft lower width plus an 8 ft recessed entry/service side
- emergency exit on the left wall
- main entry/door recess on the right side
- long central open/dance-floor zone based on the dotted floor-plan area

Some architectural details visible only in photos — exact window widths, curtain depth, chandelier dimensions, table diameter and door leaf geometry — are visual approximations rather than construction measurements.

## Planner features

- interactive 3D room with orbit, top, window-side and guest-eye views
- 95-person seating target across up to 10 tables
- white wrapped chairs, white linens/place settings and silver cutlery
- bride & groom table placed toward the window side
- movable and rotatable tables and activity stations
- Photo Booth, Polaroid scrapbook, video-message, advice, cake/sweets and DJ zones
- lavender/amethyst, sage, blush and dusty-blue palettes with gold accents
- adjustable floral and gold intensity
- guest assignments by table and family side
- décor shopping list with prices and product links
- browser save/load and JSON export/import

## Run online

This project is a static Three.js website and is designed to be published with GitHub Pages. No build command is required.
